原始命令、执行时间、工作目录、远端地址、命令参数中的自由文本均不复制。

## 已固化的交互习惯

以下来自仓库 `gx/config/zshrc` 的配置，不是从历史推测的按键使用频率：

- 历史容量 100000，共享会话历史、去重、压缩多余空白；包模式使用独立 profile 历史。
- 输入前缀后用 ↑/↓ 或 Ctrl+P/N 搜索；Ctrl+R 使用 fzf，安装 atuin 后由其接管。
- Emacs 编辑模式，Ctrl+U 删除光标前内容，Ctrl+W 按空白删除前一段；Alt+B/F 按词移动。
- `ll` / `la` / `l` 列目录；历史中三者均出现过。zoxide 可用时提供目录跳转。
- autosuggestions 可用时提供历史建议；补全支持大小写与分隔符的模糊匹配。

## 在目标机加载精选历史

在目标机交互式 Zsh 中，进入本仓库根目录后执行：

```zsh
fc -R "$PWD/gx/history/seed.zsh_history"
```

`fc -R` 将命令加载到当前会话的历史列表，不执行这些命令。加载后可通过历史检索
和建议找到它们；常用项排在文件末尾。当前 shell 的历史保存设置可能随后将其写入
目标机自己的历史文件。无需 `source` 本文件，也不要用它覆盖已有 `.zsh_history`。
精选条目不带原始时间戳，不保持完整执行顺序；缺失的 CLI 需要另外安装。
本次未对本机执行导入，也没有修改安装器或启动配置。

## 更新快照

工具 `scripts/gx_history.py::summarize` 只接收显式路径，要求 Zsh 扩展历史格式。
工具名统计只能输出固定白名单词汇；精选历史要求整个事件逐字符匹配固定命令，
不采用容易遗漏凭据的黑名单替换。未收录的命令不代表未使用。

在仓库根目录执行，先输出到临时目录，成功后再审阅并替换仓库中的两个文件：

```sh
snapshot_dir=$(mktemp -d)
python3 scripts/gx_history.py "$HOME/.zsh_history" > "$snapshot_dir/summary.json"
python3 scripts/gx_history.py "$HOME/.zsh_history" --format zsh > "$snapshot_dir/seed.zsh_history"
```

检查两个命令的退出码均为 0，并同步更新本文的事件数和表格。两次读取期间源文件
可能变化，需一致快照时应在 Python 中对同一次 `summarize` 的结果生成两个文件。
不支持普通格式或无法读取时返回 2，错误信息不回显输入路径或原文。
白名单扩展必须检查新条目是否为可公开的通用命令，不添加实际路径或登录参数。

隐私与导入回归：`python3 tests/test_gx_history.py`；该测试也由 `make test` 的
`test_gx_*.py` 发现机制执行。
